Teacher: Today we're going to learn about binary search. Can anyone tell me what happens when you look up a word in a dictionary? Do you start from page 1?

Student A: No, you kind of guess the middle and go from there.

Teacher: Exactly! That's the core idea behind binary search. Let me think through this out loud as if I were solving it for the first time. Say I'm looking for the number 42 in this sorted list: [3, 8, 15, 23, 42, 56, 91]. I start by checking the middle element, 23. Since 42 is bigger than 23, I know the answer must be in the right half. I don't need to check the left half at all — that's the key insight that makes this fast.

Student B: What if the list isn't sorted?

Teacher: Great question — binary search only works on sorted data, that's a common misconception. If your data isn't sorted, you'd need to sort it first, or use a different search method entirely.
